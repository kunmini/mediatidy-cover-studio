# 媒体库封面工坊（media.cover-studio）

为 Emby 媒体库自动生成 1920×1080 的分类封面。

![效果](docs/preview.png)

## 它做什么

- 从 Emby 每个媒体库里抓作品海报
- **按「作品名 + 年份」去重** —— 同一部片只取一张，封面不会出现重复
- 合成封面：右侧斜排圆角海报墙（15°）+ 左侧中英文标题 + 绿竖条
- 可选：左上角显示该库的媒体数量角标（如 `6198`）
- 一键写回 Emby 对应媒体库的封面

## 安装

1. MediaTidy → 系统 → 插件中心
2. 右上角「上传 ZIP」，选 `media.cover-studio-x.x.x.zip`
3. 找到「媒体库封面工坊」卡片，点「配置并启用」
4. 勾选 **调用 Emby API** 和 **独立存储**，选择你的 Emby 服务器
5. 保存

## 使用

打开插件 → 工作台：

**第一步（只需一次）**：填 Emby 地址和 API Key，保存。

> API Key 在 Emby 后台 → 设置 → 高级 → API 密钥 → 新建。

**之后每次**：点「🚀 一键生成全部封面」即可。想先看效果就点「👁 先预览不写回」。

## 设置项

| 项目 | 说明 |
|---|---|
| Emby 地址 | 如 `http://192.168.1.10:8096` |
| Emby API Key | Emby 后台生成 |
| 显示数量角标 | 封面左上角显示该库作品数 |
| 角标背景深浅 | 不透明 / 轻微透明 / 半透明（默认）/ 比较透 / 很透 |
| 封面暗色调 | 跟随海报取色（推荐）/ 固定纯色 |
| 跳过的媒体库 | 不想处理的库名 |

## 定时更新

插件 → 任务与触发器 → 新建任务 → 选「生成并写回 Emby 封面」→ 设 cron 表达式即可。

例如 `0 4 * * 0` = 每周日 04:00 自动更新封面。

## 技术说明

### 为什么需要填 API Key

MediaTidy 的插件 SDK `emby.request` 只支持 **JSON / UTF-8 文本**响应，
拿不到图片二进制。所以下载海报和上传封面都用标准库 `urllib` 直连 Emby，
需要地址 + API Key。

读媒体库列表和条目仍然走 SDK（宿主自动鉴权）。

### ⚠️ Emby 写图的坑

Emby 的 `POST /Items/{id}/Images/Primary` 接收的是 **base64 字符串**，
不是二进制流。Emby 的 OpenAPI 文档写的是 `binary format`，那是错的。

直接发二进制会得到 `HTTP 204` 但**完全不落盘**，很难排查。
本插件已按 base64 方式实现。

### 字体

插件自带思源黑体 CN（Heavy + Bold），无需额外安装。
字体随包分发，因此 ZIP 约 15MB。
